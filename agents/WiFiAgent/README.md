# WiFi Agent

## Role
Mengelola seluruh siklus hidup koneksi wireless (WiFi). Memastikan sistem tetap terhubung ke infrastruktur jaringan.

## Skills
- **Skill: Connection Management**
  - Autentikasi dan asosiasi ke SSID target dengan mode Auto-reconnect.
- **Skill: WiFi Scanning**
  - Mendeteksi jaringan yang tersedia di sekitar dan melaporkannya ke UI.
- **Skill: Signal Monitoring**
  - Memantau kualitas sinyal (RSSI) secara berkala.
- **Skill: NVS Integration**
  - Menyimpan dan membaca kredensial WiFi dari memori Flash (NVS) secara aman.
