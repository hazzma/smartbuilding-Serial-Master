# Communication Agent (RS485)

## Role
Mengelola komunikasi serial jarak jauh menggunakan protokol RS485. Menghubungkan Master dengan perangkat Slave di lapangan.

## Skills
- **Skill: UART Orchestration**
  - Konfigurasi baud rate dan frame data pada UART peripheral.
- **Skill: Flow Control (DE/RE)**
  - Mengatur switching pin Data Enable secara presisi untuk komunikasi Half-Duplex.
- **Skill: Protocol Parsing**
  - Melakukan enkapsulasi dan dekapsulasi paket data (Modbus atau custom).
- **Skill: Integrity Checking**
  - Melakukan validasi data menggunakan Checksum atau CRC (Cyclic Redundancy Check).
