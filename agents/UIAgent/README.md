# UI Agent

## Role
Mengelola logika tingkat tinggi dari antarmuka pengguna (HMI). Mengatur apa yang ditampilkan dan bagaimana navigasi antar layar bekerja.

## Skills
- **Skill: Screen Orchestration**
  - Mengelola transisi antar layar (Dashboard, Settings, WiFi Scan, dll).
- **Skill: Widget Integration**
  - Menggunakan library `SmartBuildingUI` untuk menggambar elemen visual (gauge, kartu, tombol).
- **Skill: Event Handling**
  - Menerjemahkan koordinat sentuh menjadi aksi (pindah layar, toggle switch).
- **Skill: Dynamic UI Update**
  - Memperbarui label dan grafik secara real-time berdasarkan data dari Data Agent.
